# TH Sarabun New (ฟอนต์ราชการ)

- ที่มา: ฟอนต์แห่งชาติ TH Sarabun New เวอร์ชัน 1.3 (2011) © สำนักงานส่งเสริมอุตสาหกรรมซอฟต์แวร์แห่งชาติ (SIPA)
  แจกจ่ายให้ใช้ ดัดแปลง และเผยแพร่ได้โดยไม่มีค่าใช้จ่าย — ไฟล์เว็บฟอนต์จากแพ็กเกจ npm `font-th-sarabun-new@1.0.0`
- ใช้เฉพาะหน้า "บันทึกข้อความ" (ตัวอย่าง A4 และการพิมพ์) โดยโหลดจากเว็บนี้เอง ไม่ต้องติดตั้งในเครื่อง
- ไฟล์เว็บฟอนต์นี้ถูกปรับขนาดตัวอักษรใหญ่กว่าต้นฉบับ (พยัญชนะสูง 0.612 em เทียบกับ 0.400 em ของ TH Sarabun ใน Word)
  ระบบจึงย่อขนาด pt ตาม `MEMO_WEB_FONT_PT` ให้ได้ขนาดบนกระดาษเท่ากับ TH Sarabun 16 / 20 / 29 pt
