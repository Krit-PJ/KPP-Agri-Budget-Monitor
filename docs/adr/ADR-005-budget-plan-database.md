# ADR-005: ฐานข้อมูลแผนงบประมาณ และการเลือกกิจกรรมของกลุ่มงาน

- สถานะ: อนุมัติ (ตามคำขอเจ้าของงาน 2026-11-06)
- บริบท: สำนักงานได้รับแผนจัดสรร (แบบ คง.2) เป็น PDF ซึ่งมีลำดับชั้น
  แผนงาน → ผลผลิต → โครงการ → กิจกรรม → วิธีดำเนินงาน และมีหน่วยนับ ปริมาณงาน งบประมาณ
  เจ้าของงานต้องการ:
  - เก็บแผนนี้เป็นฐานข้อมูลตามปีงบประมาณ
  - ให้แต่ละกลุ่มงานเลือกรายการที่รับผิดชอบ โดยกิจกรรมหลักเลือกซ้ำกันได้ แต่กิจกรรมย่อยสุดท้ายห้ามซ้ำ

## การตัดสินใจ
1. **ตาราง `PlanDocs` และ `PlanItems`** (ไฟล์ CORE): 1 แผน = 1 ปีงบประมาณ + แหล่งงบ + งวด
   - เก็บทุกแถวของเอกสารพร้อม `parentSeq`, `kind`, `number`, `unit`, `quantity`, `amountSatang`, `isLeaf`
2. **ระดับชั้นอนุมานจากรูปแบบเลขลำดับ**: `แผนงาน` › `ผลผลิต` › `1` › `1.1` › `1.1.1` › `+ งบ...` › `1)` › `1.1)` › `(1)` › `(1.1)` › `-`
   - การย่อหน้าหายไปเมื่อคัดลอกจาก PDF หรือ Excel จึงไม่ใช้
3. **ตรวจยอดทุกระดับก่อนบันทึก**:
   - ยอดแม่ต้องเท่ากับผลรวมลูก และยอดรวมทั้งสิ้นต้องเท่ากับผลรวมแผนงาน — ไม่ผ่านบันทึกไม่ได้ (ERROR)
   - เลขลำดับข้ามหรือไม่สอดคล้องแสดงเป็น INFO
4. **กิจกรรมย่อยสุดท้าย (leaf) 1 รายการมีผู้รับผิดชอบได้ 1 กลุ่มงาน**:
   - บังคับที่ server ภายใต้ script lock: `PlanItems.workgroupId` ว่างเท่านั้นจึงเลือกได้
   - กิจกรรมหลักใช้ร่วมกันได้โดยธรรมชาติ เพราะใต้กิจกรรมหลักเดียวมี leaf หลายรายการ
5. **เลือกแล้วสร้างข้อมูลติดตามให้อัตโนมัติ** (ไม่ต้องกรอกซ้ำ):
   - โครงการ 1 รายการต่อ (โครงการในแผน × กลุ่มงาน) ชื่อเดียวกับในแผน รหัส `P{แผนงาน}-{เลขโครงการ}-{รหัสกลุ่มงาน}`
   - กิจกรรม 1 รายการต่อ leaf พร้อมหน่วยนับและเป้าหมาย
   - งบที่ได้รับจัดสรร (ORIGINAL) เท่ากับงบของ leaf, source = `PLAN:{itemId}`
6. **ยกเลิกการเลือกได้เมื่อยังไม่มีการเบิกจ่าย**:
   - ระบบลบงบ กิจกรรม และโครงการที่ว่างแบบ soft delete
   - นำเข้าแผนซ้ำ (ปี/แหล่งงบ/งวดเดียวกัน) ได้เฉพาะเมื่อยังไม่มีกลุ่มเลือก ไม่เช่นนั้นให้นำเข้าเป็นงวดใหม่
7. **ช่องทางนำเข้า**:
   - Excel, CSV, Google Sheets (4 คอลัมน์: รายการ, หน่วยนับ, ปริมาณงาน, งบประมาณ)
   - PDF หรือรูปผ่าน Drive OCR: ได้เป็น "ร่าง" ที่ต้องตรวจ และดาวน์โหลดเป็น CSV เพื่อแก้ได้
8. แผนปี 2570 ครั้งที่ 1 (หนังสือ กษ 1004/ว 1594) ถอดเป็น `data/plans/2570-DOAE-r1-kamphaengphet.csv` แล้ว
   - ยอดตรงกับเอกสารทุกระดับ — ดู `docs/data-checks/2570-DOAE-r1.md`

## ผลกระทบ
- เมนู "แผนงบประมาณ" เป็นจุดเริ่มงานของแต่ละปี
- "เพิ่มโครงการนอกแผน" ยังมีไว้สำหรับงบที่ไม่มีเอกสาร คง.2 (เช่น งบจังหวัด)
- หน้า dashboard เดิมใช้ได้ทันที เพราะข้อมูลที่สร้างเป็นโครงการ กิจกรรม และงบตามโมเดลเดิม
