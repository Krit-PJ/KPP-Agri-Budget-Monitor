# ADR-004: การนำเข้าข้อมูลอัตโนมัติ (ผู้ใช้กรอกน้อยที่สุด)

- สถานะ: อนุมัติ (ตามความต้องการ "ผู้ใช้กรอกข้อมูลน้อยที่สุด ระบบนำเข้าข้อมูลได้แบบอัตโนมัติ")

## ช่องทาง
1. **ลากไฟล์ใส่หน้าเว็บ** (CSV/TSV/XLSX/XLS/Google Sheets link)
   - ระบบหาแถวหัวตาราง จับคู่คอลัมน์ แปลงค่า และตรวจสอบให้อัตโนมัติ
   - ผู้ใช้กดยืนยันครั้งเดียว
2. **โฟลเดอร์ Inbox ใน Drive** (`01_Imports/Inbox`)
   - วางไฟล์ไว้ แล้ว trigger ทุก 15 นาทีจะดึงไฟล์มาเตรียมนำเข้า
   - ไฟล์จะขึ้นในหน้า "งานที่ต้องดำเนินการ"
   - ถ้า Super Admin เปิด `autoCommitClean` ไฟล์ที่ไม่มี Error และ Warning เลยจะถูกนำเข้าทันที
     (ค่าเริ่มต้น: ปิด)

## ประเภทข้อมูลที่ระบบตรวจจับเอง
- `BUDGET_SUMMARY` — 1 แถวต่อโครงการ/กิจกรรม: รหัส ชื่อ กลุ่มงาน งบที่ได้รับ โอนเพิ่ม/ลด ผูกพัน เบิกจ่ายสะสม
  - งบที่ได้รับของโครงการใหม่ → สร้าง ORIGINAL allocation
  - งบของโครงการเดิมที่เปลี่ยน → ต้องมีผู้ยืนยัน และระบบสร้าง TRANSFER_IN/OUT พร้อมหมายเหตุ "ปรับตามไฟล์นำเข้า"
  - เบิกจ่ายสะสมในไฟล์ (เช่นรายงาน GFMIS) → ระบบสร้างรายการ "ปรับยอดตามไฟล์" เฉพาะส่วนต่าง
    - นำเข้าไฟล์เดิมซ้ำได้ยอดต่าง = 0 จึง idempotent
    - ส่วนต่างติดลบถือเป็น Warning ต้องตรวจ
- `DISBURSEMENT_LIST` — 1 แถวต่อรายการเบิกจ่าย: รหัสโครงการ วันที่ เลขที่เอกสาร จำนวนเงิน
  - กันรายการซ้ำด้วย (projectId, docNo, date, amount)

## กติกาความปลอดภัย
- ข้อมูลเข้าสู่ staging ก่อนเสมอ และ backend ตรวจซ้ำทุกแถว
- Admin นำเข้าได้เฉพาะกลุ่มงานในขอบเขตของตน แถวนอกขอบเขตเป็น Error
- ไฟล์ซ้ำ (SHA-256 เดียวกัน) → `DUPLICATE_IMPORT` เว้นแต่ยืนยันนำเข้าซ้ำ
- commit แบบ chunk ภายใต้ script lock ทุกแถวมี `rowKey` จึงทำซ้ำหรือ resume ได้โดยไม่เกิดรายการซ้ำ
- ค่าที่ขึ้นต้นด้วย `= + - @` tab หรือ CR ถูก escape ก่อนเขียนลงชีตและก่อน export CSV

## หนังสือปะหน้านำส่งการใช้จ่ายงบประมาณ (ไม่บังคับ)
- แนบรูป (JPG/PNG/HEIC→JPG) หรือ PDF ได้ทั้งตอนบันทึกรายการเบิกจ่ายและในหน้ารายละเอียดรายการ
  - ไฟล์เก็บที่ `02_Project_Evidence/FY{พ.ศ.}/{projectCode}` และไม่เผยแพร่สาธารณะ
- กด "อ่านข้อมูลจากรูป" → Apps Script ใช้ Drive OCR (ไม่มีค่าใช้จ่าย) แปลงเป็นข้อความ
  แล้ว `parseCoverLetter` ดึงข้อมูลต่อไปนี้พร้อมค่าความมั่นใจ:
  - เลขที่หนังสือ
  - วันที่
  - จำนวนเงิน (ทั้งตัวเลขและตัวอักษร "บาทถ้วน")
  - เรื่อง
  - รหัสโครงการ
- ระบบเติมค่าลงฟอร์มเป็นข้อเสนอ ผู้ใช้ตรวจแล้วกดบันทึกเอง ไม่มีการบันทึกอัตโนมัติ
  - ถ้าตัวเลขกับตัวอักษรของจำนวนเงินไม่ตรงกัน ระบบเตือน
