# ADR-006: ผู้รับผิดชอบ 2 ระดับ (กลุ่มงาน + หน่วยดำเนินการ) และหน้ารายงาน

- สถานะ: ยอมรับ (7 พ.ย. 2569)
- ผู้ตัดสินใจ: เจ้าของระบบ (สำนักงานเกษตรจังหวัดกำแพงเพชร)

## บริบท
- การกำหนดผู้รับผิดชอบเดิมซ่อนอยู่ลึก 6 ขั้น และเปลี่ยนกลุ่มต้องยกเลิกก่อน
- กิจกรรมหนึ่งอาจดำเนินการโดยทั้ง 11 อำเภอ บางอำเภอ หรือสำนักงานเกษตรจังหวัด และต้องติดตามร้อยละการเบิกจ่ายรายอำเภอ
- ผู้บริหารต้องการรายงานที่พิมพ์/ส่งออกได้

## การตัดสินใจ
1. **ผู้รับผิดชอบ 2 ระดับ**
   - ระดับ 1: กลุ่มงาน — ทุกกิจกรรมย่อยที่มีงบต้องมี 1 กลุ่ม (เดิม)
   - ระดับ 2: **หน่วยดำเนินการ** = สำนักงานเกษตรจังหวัด + สำนักงานเกษตรอำเภอ 11 อำเภอ (ตาราง `Units`)
2. **ใช้คำว่า "หน่วยดำเนินการ" ไม่ใช่ "หน่วยเบิกจ่าย"** — "หน่วยเบิกจ่าย" เป็นคำเฉพาะของ GFMIS (หน่วยที่มีรหัสหน่วยเบิกจ่ายเอง)
3. **แบ่งงบให้หน่วย** (`ActivityUnits`) เพราะร้อยละรายอำเภอคำนวณไม่ได้ถ้าไม่รู้งบของอำเภอ
   - ผลรวมต้องเท่างบกิจกรรมพอดี; วิธีแบ่ง: เท่ากัน / ตามปริมาณงาน / กำหนดเอง (เศษสตางค์ไปหน่วยแรก)
   - งบที่ยังไม่แบ่ง และรายการเบิกจ่ายที่ไม่ระบุหน่วย นับเป็นของสำนักงานเกษตรจังหวัด
   - เอาหน่วยที่มีรายการเบิกจ่ายแล้วออกไม่ได้
4. **เจ้าหน้าที่กลุ่มงานบันทึกเบิกจ่ายแทนอำเภอ** (เลือกอำเภอในฟอร์ม) — บัญชีเจ้าหน้าที่อำเภอทำเพิ่มได้ภายหลังโดยไม่เปลี่ยนโครงสร้าง
5. **เปลี่ยนกลุ่มงานได้ในแถว** (reassign) เมื่อยังไม่มีการเบิกจ่าย และผู้ใช้มีสิทธิ์ทั้งสองกลุ่ม — ย้ายหน่วยและแผนรายไตรมาสไปด้วย
6. **แผนการใช้จ่ายรายไตรมาส** ต่อกิจกรรม (ไม่บังคับ, `Activities.planQuarters`) — ว่างใช้เป้าร้อยละของโครงการ; แผน ณ เดือนใด ๆ ไล่ขึ้นเป็นเส้นตรงในไตรมาส
7. **กลุ่มงาน "สำนักงานเกษตรอำเภอ" (DIST) เลิกใช้** — `setup` ลบแบบ soft delete เมื่อไม่มีข้อมูลอ้างถึง
8. **รายงาน 4 แบบ** สร้างจากข้อมูลชุดเดียว (`reports.data`: กิจกรรม × หน่วย) แล้วแสดง/พิมพ์/ส่งออกจากตารางเดียวกัน
   - PDF ผ่านคำสั่งพิมพ์ของเบราว์เซอร์ (A4 แนวนอน) เพราะการสร้าง PDF ด้วย JavaScript มักวางสระ/วรรณยุกต์ไทยผิดตำแหน่ง
   - Excel (.xlsx) เขียนเองด้วย fflate: ตัวเลขเป็นตัวเลขจริง แถวรวม ตรึงหัวตาราง; CSV สำหรับใช้ต่อ
9. **ชื่อเมนูตามงานที่ทำ**: หน้าหลัก / แผนและผู้รับผิดชอบ / บันทึกการเบิกจ่าย / นำเข้าจากไฟล์ / รายงาน / ผู้ใช้งาน / ตั้งค่าระบบ

## ผลที่ตามมา
- หน้า "แผนและผู้รับผิดชอบ" ทำทุกอย่างในหน้าเดียว (เลือกกลุ่มในแถว, แผงเลือกหน่วย, ทำหลายรายการพร้อมกัน)
- Dashboard: ตาราง งบ / แผน ณ เดือนนี้ / เบิกจ่าย / ผูกพัน / คงเหลือ / % คงเหลือ แยกตามกลุ่มงาน (กางดูรายอำเภอ) หน่วยดำเนินการ แผนงาน แหล่งงบ
- ข้อมูลรายอำเภอแม่นยำเท่าที่กลุ่มงานแบ่งงบและเลือกอำเภอตอนบันทึก — dashboard แสดงจำนวนกิจกรรมที่ยังไม่แบ่ง

## ปรับปรุง 7 พ.ย. 2569 (ตามแบบ ผป.03 และความต้องการของผู้บริหาร)
- **ใช้คำ "พื้นที่ดำเนินการ"** ตามแบบ ผป.03: ระดับจังหวัด / ทั้ง 11 อำเภอ / บางอำเภอ (โค้ดภายในยังชื่อ Units)
- **เป้าหมายรายพื้นที่ต้องรวมเท่าเป้าหมายทั้งสิ้น** (กิจกรรมที่มีหน่วยนับ) และงบรายพื้นที่ต้องรวมเท่างบทั้งสิ้น — ตรวจที่ server
- **งบของพื้นที่ต้องไม่ต่ำกว่ายอดที่เบิกจ่ายแล้วในพื้นที่นั้น**
- **ค่าเริ่มต้น = ร่างแบ่งเท่ากัน** (งบเป็นบาทเต็ม, เศษกระจายทีละ 1) ยังไม่บันทึกจนผู้ใช้กด "บันทึก" แล้ว "ยืนยันและบันทึก"; กิจกรรมที่ยังไม่ยืนยันนับเป็นระดับจังหวัด
- **หน้าแผนและผู้รับผิดชอบ**: ตารางซ้าย→ขวา กิจกรรม → เป้าหมาย (ทั้งสิ้น) → งบประมาณ (ทั้งสิ้น) → กลุ่มที่รับผิดชอบ → พื้นที่ดำเนินการ; กดแก้ไขแล้วกางตารางรายอำเภอในแถว (ทีละแถว) แทนการกางทุกอำเภอพร้อมกัน (~960 แถว)
- **ฝ่ายบริหารทั่วไปไม่รับผิดชอบกิจกรรม** (`Workgroups.noActivities`) แต่คงไว้ให้ผู้ใช้สังกัด
- **รายงานสรุปสำหรับผู้บริหาร**: หน้าสรุป A4 แนวตั้ง (ตัวเลขใหญ่ 4 ช่อง, ประโยคเทียบแผน, ตารางกลุ่มงานลำดับคงที่ พร้อมหมายเหตุเป็นข้อความ "▼ ต่ำกว่าแผน" ไม่พึ่งสี) + รายละเอียด A4 แนวนอน (ลำดับ | โครงการ/กิจกรรม | กลุ่ม | พื้นที่ | งบทั้งสิ้น | เบิกจ่ายแล้ว | คงเหลือ | ร้อยละ) — "เบิกจ่ายแล้ว" ไม่รวมผูกพัน (ผูกพันแสดงเป็นหมายเหตุ) ให้ตรงกับเป้าการเบิกจ่ายของ ครม.
