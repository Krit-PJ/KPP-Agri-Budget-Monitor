# ADR-009 เปิด/ปิดการเผยแพร่ข้อมูลรายกลุ่มงาน

สถานะ: ใช้งาน (2026-11-09)

## บริบท
ช่วงเริ่มใช้งาน บางกลุ่มงานบันทึกข้อมูลยังไม่ครบ หากแสดงบนหน้าสาธารณะจะดูเหมือนเบิกจ่าย 0% หรือล่าช้า
ผู้ใช้ต้องการแสดงเฉพาะกลุ่มอารักขาพืชและพื้นที่ดำเนินการของกลุ่มก่อน

## การตัดสินใจ
- คอลัมน์ `Workgroups.hidePublic` (ค่าว่าง = แสดง) ตั้งได้โดย Mini Super / Super Admin ที่หน้า "การเผยแพร่ข้อมูลกลุ่มงาน"
  (`admin.setWorkgroupPublic`, บันทึก audit, ล้าง cache สาธารณะทันที)
- กรองที่ server (`publicFilter`) สำหรับ public.summary / public.projects / public.project / public.report และ snapshot —
  ข้อมูลกลุ่มที่ปิดไม่ถูกส่งออกทาง API สาธารณะ ไม่ใช่แค่ซ่อนบนจอ
- ตัวเลขรวมบนหน้าสาธารณะนับเฉพาะกลุ่มที่เปิด พร้อมข้อความกำกับ "ข้อมูลที่เผยแพร่: … (n จาก N กลุ่มงาน)" ทั้งบนจอและหัวรายงานที่พิมพ์
- พื้นที่ดำเนินการ (อำเภอเป้าหมาย) แสดงตามงบของกลุ่มที่เปิดโดยอัตโนมัติ พร้อมบอกจำนวนพื้นที่ที่มีงบ
- งานเจ้าหน้าที่ (แผน บันทึกเบิกจ่าย รายงานเจ้าหน้าที่) ไม่ถูกซ่อน มีป้าย "(ยังไม่เผยแพร่)" ในตัวเลือกกลุ่ม
- เมนู "พิมพ์รายงาน" ด้านบนเป็นรายงานสาธารณะเสมอ (ตรงกับหน้าภาพรวม); รายงานครบทุกกลุ่มของเจ้าหน้าที่อยู่ที่ "งานเจ้าหน้าที่ › รายงาน"
- ค่าเริ่มต้น (ครั้งเดียวตอน setup, `initPublicVisibility`): เปิดเฉพาะกลุ่มอารักขาพืช
- เข้าสู่ระบบแล้วไปหน้า "ภาพรวม" เป็นค่าเริ่มต้นสำหรับผู้ใช้ทุกคน
