# ADR-010 แถบ "กำลังทำงาน" (กลุ่มงาน + พื้นที่ดำเนินการ) และสิทธิ์ดูข้ามกลุ่ม

สถานะ: ใช้งาน (2026-11-09)

## การตัดสินใจ
- แถบ "กำลังทำงาน" ในเมนูซ้าย (มือถือ: ด้านบนเนื้อหา) เลือก **กลุ่มงาน** และ **พื้นที่ดำเนินการ** ครั้งเดียว ใช้ร่วมทุกหน้า:
  บันทึกผลการเบิกจ่าย (กรอง + แถบสรุป + เลือกอำเภอให้ฟอร์ม/บันทึกข้อความ), หน้าหลัก (`admin.overview` รับ workgroupId),
  รายโครงการ, รายงาน (กลุ่ม/พื้นที่/หัวรายงาน), บันทึกแผนงาน (ตัวกรอง "ของกลุ่มที่เลือก" + พื้นที่)
- ค่าเริ่มต้น = กลุ่มของผู้ใช้; จำค่าในแท็บ (sessionStorage ตามนโยบาย lint ที่ห้ามใช้ localStorage) และรับจากลิงก์ `?wg=&wu=`
- พื้นที่ที่เลือกได้ = เฉพาะพื้นที่ที่กลุ่มนั้นมีงบ (จาก reports.data ปีปัจจุบัน)
- **สิทธิ์ (ตามที่ผู้ใช้กำหนด):** เจ้าหน้าที่ทุกบทบาทเลือกดูกลุ่มอื่น/ทุกกลุ่มได้ → การอ่านข้อมูลงานภายใน
  (`disbursements.entryList`, `projects.list`, `projects.get`, `reports.data`, `admin.overview`) เปิดให้ทุกกลุ่ม
  และส่ง `canEdit` กลับไป; **การบันทึก/แก้ไขทุกคำสั่งยังตรวจ `requireWorkgroup` ที่ server เหมือนเดิม**
  ข้อมูลที่ยังจำกัดเฉพาะกลุ่ม: บันทึกข้อความ (มีชื่อผู้ลงนาม), ไฟล์แนบ/รูปหนังสือ, การนำเข้าไฟล์ (ปฏิเสธแถวนอกสิทธิ์)
- หน้าเว็บแสดง "ดูอย่างเดียว" และซ่อนปุ่ม/ฟอร์มแก้ไขของกลุ่มอื่น (`.is-readonly`)
