# ADR-002: Admin เข้าสู่ระบบด้วยหมายเลขโทรศัพท์อย่างเดียว (ความเสี่ยงที่เจ้าของงานยอมรับ)

- สถานะ: อนุมัติโดยเจ้าของงาน (2026-11-05) — **Accepted risk**
- บริบท: เจ้าของงานต้องการให้ใช้งานง่ายที่สุดและเหมือนระบบ Agri-Risk Map
  คือ Admin กรอกเบอร์โทรศัพท์แล้วเข้าระบบได้ทันที โดยไม่ต้องมี OTP หรือรหัสผ่าน

## ความเสี่ยง (แจ้งเจ้าของงานแล้ว)
เบอร์โทรศัพท์ไม่ใช่ความลับ ใครที่รู้เบอร์ของ Admin ที่ได้รับอนุมัติแล้วจะเข้าระบบแทนได้
และทำรายการในขอบเขตของ Admin คนนั้นได้

## มาตรการชดเชย (ไม่เพิ่มภาระการกรอกของผู้ใช้)
1. Throttling ต่อหมายเลข: ผิด/ไม่พบเกิน 5 ครั้งใน 15 นาที → ระงับชั่วคราว 15 นาที
2. Throttling ทั้งระบบ: ล้มเหลวเกิน 30 ครั้งใน 10 นาที → ชะลอการล็อกอินของ Admin ทั้งหมด
   และขึ้นการแจ้งเตือนในหน้า Super Admin (กันการสุ่มเบอร์)
3. ข้อความตอบกลับเดียวสำหรับ "ไม่พบ" และ "รออนุมัติ" เพื่อลดการสำรวจเบอร์
4. บันทึกอุปกรณ์: ล็อกอินจากอุปกรณ์ใหม่ถูกติดป้าย "อุปกรณ์ใหม่" ในรายงานการเข้าใช้และในหน้าภาพรวมของ Super Admin
5. สิทธิ์เสี่ยงสูงสงวนไว้ให้ Super Admin: ยกเลิก (void) รายการที่อนุมัติ/จ่ายแล้ว,
   override งบติดลบ, จัดการผู้ใช้/สิทธิ์, ตั้งค่า, กู้คืน
6. ตรวจสถานะบัญชีจากชีตทุก request และเพิกถอน token ทันทีเมื่อระงับบัญชี (tokenVersion)
7. Token อายุ 8 ชั่วโมง เก็บใน sessionStorage, ไม่มีเบอร์โทรใน payload
8. Audit ทุกการเปลี่ยนแปลง พร้อม before/after ที่ไม่มี PII
9. ข้อมูลการเงินแก้แบบ void-and-replace จึงย้อนดูและกู้คืนได้เสมอ

## เมื่อใดควรทบทวน
- มีเหตุการณ์ล็อกอินโดยไม่ได้รับอนุญาต หรือพบการสุ่มเบอร์ใน login report
- ระบบเริ่มใช้กับข้อมูลที่ต้องรับรองทางการเงิน
ทางเลือกที่พร้อมเปิดได้ในอนาคต: PIN 6 หลักที่ตั้งเองครั้งแรก หรือ Google Sign-In (ไม่มีค่าใช้จ่ายทั้งคู่)
