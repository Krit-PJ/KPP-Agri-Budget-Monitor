# ADR-008 บันทึกข้อความ "ตรวจสอบเอกสารเพื่อขอเบิกเงินราชการ"

สถานะ: ใช้งาน (2026-11-08)

## บริบท
เจ้าหน้าที่กลุ่มต้องทำบันทึกข้อความตรวจสอบเอกสารทุกครั้งที่อำเภอส่งหลักฐานขอเบิก และกรอกยอดเงิน
(งบทั้งหมด / เบิกมาแล้ว / คงเหลือ / ตัวอักษร) เอง ทำให้ตัวเลขผิดได้ และต้องบันทึกยอดในระบบซ้ำอีกรอบ

## การตัดสินใจ
1. **บันทึก = เบิกจ่าย**: กด "ยืนยันและบันทึก" แล้วระบบสร้างรายการเบิกจ่ายสถานะ `APPROVED` (นับเป็นเบิกจ่ายแล้วทันที)
   วันที่ = วันที่บันทึก, เลขที่ = prefix ของกลุ่ม + เลขที่เจ้าหน้าที่กรอก (ระบบไม่ออกเลขหนังสือเอง)
2. **ตัวเลขคำนวณที่ server เสมอ**: งบของกิจกรรม, ยอดเบิกมาแล้ว (ไม่รวม VOID, ทุกอำเภอ), คงเหลือ, ตัวอักษร —
   ค่าที่หน้าเว็บส่งมาถูกทับ; ข้อความที่ผู้ใช้แก้เองต้องมียอดตรงกับยอดล่าสุด (`memoOverrideStale`)
3. **ไม่มีส่วนฝ่ายบริหารทั่วไป/การเงิน** — มีเฉพาะการตรวจของเจ้าหน้าที่กลุ่ม (ถูกต้อง / ส่งคืนแก้ไข + เหตุผล / ส่งฝ่ายบริหารฯ)
   ยังคงช่อง "อนุมัติ" ด้านล่าง (ลบได้ภายหลังถ้าต้องการ)
4. **ผู้ลงนาม**: ซ้าย = ผู้ใช้ที่เข้าสู่ระบบ (ข้อมูลของฉัน: คำนำหน้า + ชื่อ + ตำแหน่งเต็ม), ขวา = หัวหน้ากลุ่มจากค่าหัวบันทึกของกลุ่ม
   (แก้รายฉบับได้). แก้บันทึกภายหลังคงผู้จัดทำเดิม
5. **รหัสงบประมาณ 20 หลัก / รหัสกิจกรรมหลัก 17 หลัก** ไม่มีในไฟล์แผน → กรอกครั้งแรกในบันทึก แล้วจำไว้ที่ Activities
6. **ไฟล์**: Google Doc (แก้ไขได้) + PDF ใน `02_Project_Evidence/FY{ปี}/{รหัสโครงการ}/บันทึกข้อความ` แชร์แบบส่วนตัว;
   แก้ไขผ่านระบบ = ฉบับใหม่ (revision+1, ไฟล์ใหม่ ไฟล์เดิมไม่ถูกลบ). สร้างไฟล์ไม่สำเร็จไม่ยกเลิกการเบิก (กด "สร้างไฟล์อีกครั้ง")
7. **แก้ยอดเงิน/วันที่/เลขที่** ได้เฉพาะ Super Admin โดย void-and-replace (ADR-002)
8. **รูปแบบหน้า**: A4 ขอบซ้าย 3 ซม. ขวา 2 ซม., ครุฑ 1.5 ซม., ย่อหน้าแรก 2.5 ซม., ค่าเริ่มต้นชิดซ้าย (เลือกชิดขอบทั้งสองด้านได้),
   ไม่มีเส้นใต้ "เรื่อง" ตามระเบียบ. ฟอนต์ Sarabun (Google) ซึ่งตัวใหญ่กว่า TH Sarabun ~1.46 เท่า
   จึงใช้ 11 / 13.5 / 20 pt ให้ได้ขนาดบนกระดาษเท่ากับ TH Sarabun 16 / 20 / 29 pt (`MEMO_FONT_PT`)
9. **การตัดคำ**: Intl.Segmenter (พจนานุกรม ICU) + กลุ่มห้ามตัด (จำนวนเงิน+บาท, ข้อความในวงเล็บ, รหัส, คำย่อ);
   โหมดชิดขอบแทรกช่องว่างกว้างศูนย์ระหว่างคำไทยเพื่อกระจายระยะที่ขอบเขตคำ (ไม่แยกตัวอักษรในคำ)
